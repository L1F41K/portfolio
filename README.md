# antoweb — портфолио

Одностраничный сайт-визитка. Чистый HTML/CSS/JS, без зависимостей и сборки.

## Запуск

Из-за iframe-превью проектов сайт лучше открывать через локальный сервер
(при открытии `index.html` двойным кликом встроенный capetownian может не
подгрузить свои скрипты из-за ограничений `file://`).

```bash
# из папки portfolio
python -m http.server 8777
# открыть http://127.0.0.1:8777
```

## Структура

```
portfolio/
├── index.html            # разметка страницы
├── assets/
│   ├── css/style.css     # дизайн-система и стили
│   └── js/main.js        # анимации, ленивые iframe, меню
└── projects/
    ├── capetownian/      # локальная статичная копия сайта (для живого превью)
    └── archilite/assets/ # реальные материалы проекта (hero + кейсы)
```
